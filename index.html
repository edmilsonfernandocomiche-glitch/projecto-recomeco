Notificações diárias

Escolhe os horários para os lembretes. As notificações do navegador podem exigir que a aplicação esteja instalada/aberta e que o sistema autorize alertas. Esta versão não garante alertas quando o navegador está fechado.

Para alertas fiáveis em segundo plano, a etapa futura é uma aplicação Android nativa ou uma PWA alojada e configurada com notificações push. Não introduzas dados pessoais sensíveis para activar lembretes.

Regras do Recomeço

1. Começa pequeno

Três tarefas importantes são melhores do que uma lista enorme que nunca executas.

2. Sem apostas

Não uses trading para recuperar perdas nem peças dinheiro para jogar. Bloqueia plataformas e cria barreiras ao acesso ao dinheiro.

3. Recaída não é desistência

Interrompe o comportamento, regista o gatilho, procura apoio e retoma o plano. Não persigas perdas.

4. Integridade

Faz promessas realistas, diz a verdade e repara o que conseguires com acções concretas.

5. Fé, saúde e relações

Reserva tempo para a vida espiritual, movimento físico, descanso e contacto humano. O apoio profissional pode ser importante para ansiedade e jogo compulsivo.

6. Protege os teus dados

Os registos ficam neste navegador. Exporta cópias regularmente.
